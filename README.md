# Chess

A responsive chess game you can play against the computer. It runs as a static website and can be hosted directly with GitHub Pages.

## Play locally

Download or clone the repository, then open `index.html` in a modern browser. An internet connection is required to load the chess rules library and web fonts from their CDNs.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The game includes legal chess moves, check/checkmate, stalemate, castling, en passant, promotion, draw rules, three AI difficulty levels, captured pieces, move history, undo/redo, board flip, color selection, and a persistent light/dark theme. The interface supports mouse and touch controls and adapts to mobile, tablet, and desktop screens.
